04 / SCOPE & LIMITATIONS

Useful signals.
Human judgment matters.

This project uses the supplied 47,692-post cyberbullying dataset and follows the IEEE paper’s sentiment plus machine learning direction. The local model is evaluated on a stratified holdout set; the score shown above is measured here and is separate from the paper’s reported result.

Text-only classification can miss context, sarcasm, reclaimed language, and conversational history. Use predictions to support review, never as a standalone moderation decision.
